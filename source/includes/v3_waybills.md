A Waybill is a document that represents the contents of a shipment ready for transport and processing. It details
the exact quantity, price and delivery details of the individual packages. 
Perform the simple operations mentioned below to create and manage your Waybill pre alert.

| Attribute                     | Type                             | Description                                                                                                                                                                                                      |
|-------------------------------|----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `id`                          | <span class=type>string</span>   | Unique ID of a waybill. This is used as an identifier. The ID is either your own `reference` given at creation or generated by the system.                                                                       |
| `masterWaybillNumber`         | <span class=type>string</span>   | Identifies the total shipment. If `transportType` is `air` the number must have the format `123-12345678`; the first three digits are the airline prefix.                                                         |
| `transportType`               | <span class=type>string</span>   | The transport type of the waybill. Values are `air`, `road`, `train`, `sea`.                                                                                                                                      |
| `customer`                    | <span class=type>string</span>   | Customer name of the account associated with the waybill.                                                                                                                                                        |
| `customer_code`               | <span class=type>string</span>   | Code of the customer the waybill belongs to.                                                                                                                                                                     |
| `status`                      | <span class=type>string</span>   | The current waybill status: `pre_upload`, `created`, `noa_received`, `received`, `ready_to_scan`, `scanning...`, `pending_clearance`, `partial`, `inbound`, `part_out`, `outbound`, `failed`.                      |
| `statusChangeUtc`             | <span class=type>datetime</span> | Date and time the waybill last changed, in UTC.                                                                                                                                                                  |
| `statusChangeLocalTime`       | <span class=type>datetime</span> | Date and time the waybill last changed, in the local time of the warehouse (Europe/Amsterdam).                                                                                                                   |
| `statusChangedHuman`          | <span class=type>string</span>   | Human readable time since the last change, for example `4 minutes ago`.                                                                                                                                          |
| `bigBagCount`                 | <span class=type>integer</span>  | The number of pieces (BigBags/Boxes/Units) expected for the shipment.                                                                                                                                            |
| `grossWeight`                 | <span class="type">float</span>  | The given gross weight for the shipment.                                                                                                                                                                         |
| `airline`                     | <span class=type>object</span>   | The airline of the incoming flight, with `trackingLink`, `name`, `prefix`, `code` and `copyNumber`. Only present when the waybill has an airline.                                                               |
| `destinationFlightNumber`     | <span class=type>string</span>   | The incoming flight number to the destination airport. For the Alline warehouse the destination airport is Schiphol (AMS).                                                                                       |
| `flight_date`                 | <span class=type>date</span>     | The arrival date given at creation as `eta`, in format `yyyy-mm-dd`.                                                                                                                                              |
| `eta`                         | <span class=type>datetime</span> | The estimated arrival time at the destination airport, in local time. Updates automatically when a known flight number and arrival date are given.                                                               |
| `declarationType`             | <span class=type>string</span>   | The type of customs declaration for the shipment: `full`, `partial` or `none`.                                                                                                                                    |
| `parcels`                     | <span class=type>array</span>    | The `finalMileTrackingNumber` of every parcel added to the waybill.                                                                                                                                              |

The attributes below are only present once the waybill is confirmed (status is not `pre_upload`).

| Attribute                     | Type                             | Description                                                                                                                                                                                                      |
|-------------------------------|----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `inboundComplete`             | <span class=type>boolean</span>  | Indicates if the inbound scan is (temporarily) completed.                                                                                                                                                        |
| `totalBagsUploaded`           | <span class=type>integer</span>  | The number of BigBags/Boxes/Units uploaded for this waybill.                                                                                                                                                      |
| `totalParcelsUploaded`        | <span class=type>integer</span>  | The number of parcels uploaded for this waybill.                                                                                                                                                                 |
| `parcelsInbound`              | <span class=type>integer</span>  | The number of parcels currently in the warehouse.                                                                                                                                                                |
| `parcelsInboundPercentage`    | <span class=type>string</span>   | The percentage of parcels currently in the warehouse, for example `25%`.                                                                                                                                          |
| `parcelsReleased`             | <span class=type>integer</span>  | The number of parcels released by customs.                                                                                                                                                                       |
| `parcelsReleasedPercentage`   | <span class=type>string</span>   | The percentage of parcels released. Note: when none are released the value is `0 %` (with a space).                                                                                                              |
| `parcelsOutbound`             | <span class=type>integer</span>  | The number of parcels outbound.                                                                                                                                                                                  |
| `parcelsOutboundPercentage`   | <span class=type>string</span>   | The percentage of parcels outbound.                                                                                                                                                                              |
